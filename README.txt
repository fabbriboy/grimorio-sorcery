Grimório Sorcery - como publicar no GitHub Pages

1. Crie um repositório público no GitHub, por exemplo "grimorio-sorcery".
2. Envie todo o conteúdo desta pasta (index.html, sw.js, manifest.json, ícones e a pasta img).
3. No repositório: Settings > Pages > Source: "Deploy from a branch", branch "main", pasta "/ (root)". Salve.
4. Em um ou dois minutos o site fica em https://SEU-USUARIO.github.io/grimorio-sorcery/

Para instalar como app no celular: abra o link no Chrome (Android) e toque em "Instalar app" ou "Adicionar à tela inicial".
No iPhone: abra no Safari, botão Compartilhar, "Adicionar à Tela de Início".
Depois de aberto uma vez, funciona sem internet.
